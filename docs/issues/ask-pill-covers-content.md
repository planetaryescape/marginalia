# The Ask pill floats over content mid-article

Seen 2026-10-16 at 1440×900: the floating "Ask about this article /" pill sits over the bottom of an open summary's idea map. It already hides while the back matter is in view (rung 1), but elsewhere it can cover text or controls, against "nothing covers the text" (principle 1). Consider hiding it while the front matter is open, or docking it in the left margin with the return chip.
